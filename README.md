# GoalVault Autopay

**A savings goal that pays itself out the moment it is fully funded — no keeper, no bot, no button to press.**

Built for the **Reactive Omni Buildathon** (DoraHacks), track **Set It and Forget It**.
Testnet only: Ethereum Sepolia + Reactive Lasna. No real funds are involved anywhere.

## The problem

On-chain savings goals, group collections, and escrow-style pots all share an
annoying last step: when the target is reached, *somebody* has to notice and
send the transaction that releases the money. Miss it, and funds sit idle;
automate it off-chain, and you are trusting a bot, a server, and a private key
that have to stay online forever.

## The solution

Two contracts and one event subscription replace the babysitter:

| Contract | Chain | Role |
|---|---|---|
| `GoalVault` | Ethereum Sepolia (11155111) | Holds goal funds. Anyone can create a goal (beneficiary + target) and deposit toward it. |
| `GoalWatcher` | Reactive Lasna (5318007) | Reactive contract subscribed to the vault's `Deposited` events. When a deposit crosses the target, it requests a callback that releases the funds. |

### The full loop

1. A user creates a goal and deposits toward it on Sepolia. Each deposit emits
   `Deposited(goalId, depositor, amount, totalFunded, target)`.
2. Reactive Network delivers the log to `GoalWatcher.react()` on Lasna
   (~1-second blocks, instant finality).
3. If `totalFunded >= target` and the goal has not fired yet, the watcher calls
   `SYSTEM.requestCallbackV_1_0(...)` targeting `GoalVault.release(goalId)` on Sepolia.
4. The Sepolia callback proxy invokes `release()`; the vault authenticates the
   call twice (it must come from the proxy, and on behalf of the authorized
   watcher) and pays the full funded amount to the beneficiary.

After the final deposit, **zero human transactions** are needed. That is the
whole demo: deposit #1 below target → nothing happens; deposit #2 crosses the
target → the beneficiary is paid automatically.

### Why it is safe

- `release()` can only be called by the Reactive callback proxy
  (`onlyServiceProvider`) and only for callbacks originating from the
  authorized `GoalWatcher` (`onlyCallbackSender`); the proxy itself overwrites
  the payload's first argument with the true reactive sender, so it cannot be
  spoofed by a direct call.
- The watcher fires at most once per goal (`triggered` mapping) and ignores
  logs from any other chain, contract, or event.
- A goal's owner can cancel before release and reclaim all deposits.
- Goal accounting lives in storage per goal, so payouts always send the exact
  funded amount.

## Run it

Prerequisites: Node.js 20+, Foundry (`forge`), and a throwaway testnet key in
`.keys/deployer.key` funded with a little Sepolia ETH (see `SUBMISSION.md` —
public faucets require an account or a browser captcha, which is the one step
that cannot be done headlessly).

```bash
forge build && forge test          # 8 tests, incl. the full reactive loop
node scripts/01-fund-lasna.mjs     # 0.1 SepETH -> 10 lREACT
node scripts/02-deploy.mjs         # deploy + wire + fund reserves
node scripts/03-demo.mjs           # the demo: goal fills, payout fires itself
```

Serve `frontend/` next to `deployments.json` (e.g. `npx serve .` from the repo
root) to watch goal progress and watcher counters live.

## Design notes

- Built on the official `reactive-lib-omni` base contracts (`AbstractReactive`,
  `AbstractCallback`) — the Omni pattern: subscriptions and callbacks go
  through the system contract, and `react()` is guarded by `onlySystem`.
- Callback gas limit is 500,000 (protocol minimum is 100,000; the proxy
  withholds overhead before forwarding).
- Fees follow the Reactive economy model: the watcher pays for reactive
  transactions in lREACT, the vault pays for callback delivery in SepETH, both
  via reserves (`depositTo()`) with the inherited `pay()` as backstop. Either
  contract exposes `coverDebt()` so it can be revived if it ever stalls.
- Deliberately out of scope: yield/interest on deposits, swaps, price feeds.
  The vault holds plain native ETH and pays it out; nothing else.
